## About

I build small, sharp tools and run them from a phone more often than is reasonable.

Mostly **Android / Termux automation**, **Telegram bots**, **OSINT tooling** and
low-level things that have to survive on ARM and a limited battery. I care about
scripts that fail loudly, logs that don't leak secrets, and binaries that don't
need a datacenter.

- 🔭 Currently building [NexusIntelligence](https://github.com/AdV1PeR/osinting) — a modular async OSINT framework
- 📱 Daily driver: Samsung A52, Termux, no root, Shizuku instead of adb
- 🧰 Languages I actually ship: Go, Python, Rust, Kotlin, Bash
- 🎯 Interested in: recon automation, Telegram infrastructure, Android internals
