## About

I'm a vibe coder and a cybersecurity student at BSU. I know a bit about
programming, networking and security — enough to build something, break it,
and then spend an evening figuring out why. Most of my projects start as an
idea plus a lot of help from AI, and I'm not going to pretend otherwise.

- 🎓 Studying **cybersecurity** at BSU, Faculty of Radiophysics and Computer Technologies (RFiKT)
- 🎯 Goal: **DevOps engineer** — Linux, containers, CI/CD, infrastructure
- 🧪 Learning by building small tools for Android/Termux, Telegram and OSINT
- 🧠 Actually comfortable with: Linux, Bash, Git, and googling error messages
- 📚 Currently learning: Docker, CI/CD, networking in depth, more Python and Go
- 🙃 Not a senior and not a pentester yet — just consistently curious
